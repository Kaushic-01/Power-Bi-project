#  Video Games Sales Analysis – Power BI Project

## Project Overview

This **Power BI project** provides a detailed analysis of the **global video game industry**, focusing on sales performance, publisher trends, platform popularity, and genre distribution.

The **interactive Power BI dashboard** helps users uncover insights about **regional performance**, **top-selling titles**, **publisher dominance**, and **evolving gaming trends** over the years.

This project serves as an excellent resource for those interested in **data visualization**, **business analytics**, and **Power BI storytelling** using real-world datasets.

---

##  Objectives

* Analyze **global, regional, and publisher-wise video game sales**.
* Identify **top-performing platforms** and their market share.
* Compare **genre popularity** across different regions (NA, EU, JP, Global).
* Examine **yearly trends** in game releases and sales performance.
* Highlight **top publishers and developers** contributing to the industry’s success.

---

##  Data Source

**File:** `VG Games.pbix`
**Dataset Name:** Video Game Sales Dataset
**Records:** 16,500+ video game titles
**Fields:** Title, Platform, Year, Genre, Publisher, Sales (NA, EU, JP, Other, Global)

Key fields include:

* **Title** – Name of the video game
* **Platform** – Console or system (e.g., PS4, Xbox, PC, Switch)
* **Genre** – Game category such as Action, Sports, or Role-Playing
* **Publisher** – Game publisher name
* **Year** – Release year of the game
* **Sales Metrics** – Regional and global sales in millions
